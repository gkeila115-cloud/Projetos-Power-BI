Análise de incidentes de Telecomunicações com IA e automação

1. Sobre o projeto

Este projeto apresenta uma análise de incidentes de telecomunicações utilizando Power BI, com o objetivo de transformar dados operacionais em informações visuais que auxiliem na identificação de padrões, acompanhamento de indicadores e identificação de oportunidades de automação.

A base de dados utilizada é **fictícia**, criada exclusivamente para fins de estudo e desenvolvimento de portfólio.

1.  Objetivo

O projeto tem como objetivo analisar os incidentes de telecomunicações e responder algumas perguntas de negócio, como:

- Qual o volume de incidentes registrados?
    - Qual o tempo médio de resolução?
    - Quantos incidentes foram resolvidos?
    - Quais categorias apresentam maior volume de ocorrências?
    - Quais cidades e operadoras concentram mais incidentes?
    - Quantos incidentes apresentam potencial de automação?
    - A automação pode contribuir para a redução do tempo de resolução?
1. Base de dados

A base possui **50 registros fictícios** de incidentes de telecomunicações.

Entre as informações analisadas estão:

- Data de abertura;
    - Data de encerramento;
    - Operadora;
    - Cidade;
    - Estado;
    - Unidade;
    - Categoria do incidente;
    - Prioridade;
    - Status;
    - Tempo de resolução;
    - Indicador de automatização.

Os dados foram inicialmente estruturados no **Microsoft Excel** e posteriormente tratados utilizando o **Power Query**.

1. Tecnologias utilizadas
- **Microsoft Excel** - criação e organização da base de dados;
    - **Power Query** - tratamento e transformação dos dados;
    - **Power BI** - criação do dashboard e visualizações;
    - **DAX** - criação de medidas e indicadores;
    - **GitHub** - documentação e publicação do projeto.

5. Tratamento dos dados

Antes da construção do dashboard, foram realizadas etapas de preparação e padronização da base, incluindo:

- Remoção de colunas desnecessárias;
    - Correção e padronização de datas;
    - Padronização de cidades;
    - Padronização de operadoras;
    - Tratamento de valores em branco;
    - Padronização dos valores de status;
    - Padronização do campo de automatização;
    - Criação e utilização de medidas para análise dos indicadores.
1. Dashboard
Dash operacional.png

O dashboard foi dividido em duas páginas principais.

1. Dashboard Operacional

A primeira página apresenta uma visão geral dos incidentes e busca responder:

> **O que está acontecendo na operação?**
> 

Entre os principais indicadores e análises estão:

- Total de incidentes;
    - Tempo médio de resolução;
    - Incidentes resolvidos;
    - Incidentes automatizáveis;
    - Evolução mensal dos incidentes;
    - Incidentes por categoria;
    - Incidentes por operadora;
    - Incidentes por cidade;
    - Filtros interativos para exploração dos dados.

2. IA e Automação

A segunda página apresenta uma análise voltada ao potencial de automação dos incidentes.

Busca responder:

> **Onde a automação pode gerar valor para a operação?**
> 

São analisados:

- Quantidade de incidentes automatizáveis;
    - Percentual de incidentes automatizáveis;
    - Tempo médio de resolução dos incidentes automatizáveis;
    - Tempo médio dos incidentes não automatizáveis;
    - Comparação entre os dois cenários;
    - Categorias com maior potencial de automação;
    - Operadoras com maior concentração de incidentes automatizáveis;
    - Cidades com maior concentração de incidentes automatizáveis;
    - Economia média de tempo proporcionada pela automação
1. IA e Automação

A análise também apresenta possibilidades de aplicação de inteligência artificial e automação na gestão de incidentes, como:

- Classificação automática de incidentes;
    - Identificação de ocorrências recorrentes;
    - Priorização de chamados;
    - Direcionamento automático para equipes;
    - Geração de alertas;
    - Identificação de padrões nos incidentes;
    - Apoio à tomada de decisão.

As possibilidades apresentadas representam **oportunidades de aplicação**, não automações efetivamente implementadas neste projeto.

1. Principais insights

Os principais insights serão apresentados após a conclusão da análise dos dados e estarão relacionados ao volume de incidentes, tempo de resolução e potencial de automação identificado na base.
