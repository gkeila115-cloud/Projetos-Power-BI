Marketing de Moda - Análise de Campanhas 2026
Sobre o projeto

Projeto de prática em análise de dados com foco no desempenho de campanhas de marketing de uma marca fictícia do setor de moda.

O objetivo foi explorar os dados de campanhas, organizar a base e desenvolver um dashboard para analisar receita, investimentos, compras, canais, categorias e evolução mensal dos resultados.

Objetivos da análise
Identificar a receita total gerada.
Calcular o investimento total.
Comparar as compras por canal.
Identificar as campanhas com maior investimento.
Analisar a receita por categoria.
Comparar a receita gerada pelos canais.
Acompanhar a evolução da receita ao longo do tempo.
Acompanhar a evolução dos investimentos ao longo do tempo.
Ferramentas utilizadas
Microsoft Excel
Power Query
Microsoft Power BI
Figma
Etapas do projeto
Exploração da base de dados.
Definição das perguntas de investigação.
Identificação das colunas necessárias para cada análise.
Limpeza e padronização dos dados.
Criação de medidas e indicadores no Power BI.
Prototipação do dashboard no Figma.
Construção e validação dos visuais.
Dashboard

A análise apresenta indicadores de receita, investimento e compras, além de gráficos para comparar campanhas, categorias e canais e acompanhar a evolução mensal dos resultados.

Dados

A base utilizada é fictícia e destinada à prática de análise de dados.

Observação

Este projeto foi desenvolvido para fins de aprendizagem e prática de análise de dados com Power BI.
